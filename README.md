# Deep Learning Fundus Image Analysis for Early Detection of Diabetic Retinopathy

## 📌 Description
This project uses deep learning techniques to detect diabetic retinopathy from retinal fundus images.  
The model is trained using the Diabetic Retinopathy dataset from Kaggle using Xception Transfer Learning Model.

---

## 🛠 Technologies Used
- Python
- TensorFlow
- Flask
- CNN
- Google Colab

---

## 📂 Dataset
Dataset used for training the model:  
https://www.kaggle.com/datasets/arbethi/diabetic-retinopathy-level-detection

---

## 🔄 Project Flow
1. User Login  
2. Upload Fundus Image  
3. Model Prediction  
4. Display DR Stage
